## 問題回答

**問題一：為什麼 `"4"` 要先轉成數字，才能用於分攤計算？**

`"4"` 是文字，不能直接作為除法運算的人數。先用 `int(people)` 轉成整數 `4`，才能用應付總額除以人數，算出每人費用。

**問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼不同？**

先扣券後的餐費是 1,200－100＝1,100 元，對這個金額收 10% 服務費為 110 元，應付總額是 1,100＋110＝1,210 元。這比題目規定的 1,220 元少 10 元，因為題目規定服務費以折價前的原始餐費 1,200 元計算，服務費應為 120 元。
